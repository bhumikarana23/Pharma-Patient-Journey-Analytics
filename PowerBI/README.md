# Power BI Dashboard

This folder contains the Power BI dashboard developed to visualize patient treatment journeys, therapy switching behavior, clinical factors, and patient segments.

## Objective

The dashboard provides an interactive view of patient treatment patterns and switching behavior to support data-driven pharmaceutical analytics.

## Dashboard Analysis

- Overall patient and treatment KPIs
- Therapy switching trends
- Switching rates by current therapy
- Switching by disease severity
- Switching by medication adherence
- Switching by adverse events
- Switching by treatment outcome
- Treatment discontinuation analysis
- Patient segment comparison
- High-switching patient characteristics
- Interactive filtering using slicers

## Key KPIs

- Total Patients
- Therapy Switching Rate
- Treatment Discontinuation Rate
- Average HbA1c
- Average Medication Adherence
- Average Treatment Cost Index
- Average Annual Visits

## Key Visualizations

- Therapy switching distribution
- Switching rate by current therapy
- Switching rate by disease severity
- Switching rate by patient segment
- Adherence vs. switching behavior
- Adverse events vs. switching
- Treatment outcome distribution
- Treatment discontinuation by therapy

## Tools & Techniques

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Interactive Slicers
- KPI Cards
- Charts and Tables

## Dashboard Purpose

The dashboard translates patient-level analytical results into an interactive business intelligence view, helping identify treatment-switching patterns and patient groups requiring further analysis.

## Note

The dataset used in this project is synthetic and does not contain real patient information. The dashboard is intended for analytical and portfolio demonstration purposes.
