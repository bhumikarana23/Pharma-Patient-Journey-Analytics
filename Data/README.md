# Dataset

This folder contains the raw and processed datasets used for the **Pharma Patient Journey Analytics: Treatment Switching & Patient Segmentation** project.

## 📄 Files

### 1. `pharma_patient_journey_dataset.csv`

**Raw Dataset**

This is the original synthetic patient-level dataset created for the project. It contains demographic, disease, treatment, clinical, adherence, adverse-event, and treatment-outcome information.

The dataset is used to analyze:

* Patient treatment journeys
* Therapy switching patterns
* Treatment discontinuation
* Patient characteristics and treatment outcomes
* Factors associated with treatment switching

### 2. `pharma_patient_journey_dataset_cleaned.xlsx`

**Edited / Cleaned Dataset**

This is the processed version of the raw dataset prepared for downstream analysis. Data types, categorical values, missing or duplicate records, and inconsistencies were reviewed and handled where required.

The cleaned dataset is used for:

* Exploratory Data Analysis (EDA)
* Statistical analysis
* Feature preparation
* Machine learning
* Patient segmentation
* SQL analysis
* Power BI visualization

## 🔄 Data Preparation Workflow

```text
Raw Dataset
     ↓
Data Inspection
     ↓
Data Cleaning & Standardization
     ↓
Feature Preparation
     ↓
Analysis-Ready Dataset
```

> **Note:** The dataset is synthetic and created for educational and portfolio purposes. It does not contain real patient information and should not be used for clinical decision-making.
